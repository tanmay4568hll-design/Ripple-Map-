ADSA & DBMS Academic Viva Guide

1. System Architecture & Core Concept

RippleMap models complex software and physical networks as directed graphs $G = (V, E)$, simulating how a single point failure ripples through dependent components. Forward edges define influence propagation ($u \to v$ means $u$ influences $v$).

2. ADSA Graph Algorithms Implemented

  • Cascade Impact Propagation: Attenuated shockwave engine modeling shock dampening via component resilience.
  • BFS Concentric Waves: Level-by-level wave expansion using custom FIFO queues.
  • Dijkstra Shortest Propagation Time: $O(E \log V)$ priority queue finding earliest failure arrival times.
  • Tarjan's SCC & Cycles: $O(V + E)$ low-link discovery of cyclical deadlock clusters.
  • Articulation Points & Bridges: Identification of Single Points of Failure (SPF).
  • Kruskal's MST with DSU: Disjoint Set Union with path compression and union by rank.
  • Greedy Mitigation Advisor: Optimization algorithm identifying top-K shielding candidates to minimize blast radius.

3. DBMS 3NF Relational Model

Normalized schema with tables scenarios, nodes, edges, events, simulation_runs, simulation_results, mitigation_plans, and immutable audit_log populated by automatic database triggers.
